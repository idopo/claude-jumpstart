# Maintaining claude-jumpstart (Ido only)

Training kit (deck + take-home repo) teaching a neuroscience lab to use Claude Code and GSD.
Planned and built as **Phase 48 of the MICS backend GSD project**
(`~/mics-backend/.planning/phases/48-*`); this repo holds only deliverables.

Brief: `IDEA.md`. Verified facts: `docs/FACTS_VERIFIED_2026-11-01.md`.
Build log (a deliverable): `docs/META_HOW_THIS_WAS_BUILT.md`.

## Rules
- Every session that touches this repo appends an entry to `docs/META_HOW_THIS_WAS_BUILT.md`.
- No Claude Code claim goes into a slide or doc without a code.claude.com / support.claude.com URL.
- Reuse the assets listed in `IDEA.md` §3 before writing new ones.
- Keep CLAUDE.md and every template under 200 lines.
- Never run GSD commands inside this repo or `demo/`; GSD lives in `~/mics-backend`.
