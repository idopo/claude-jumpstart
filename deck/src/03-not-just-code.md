Anthropic's own usage research: writing and data analysis rose from about a tenth to about a fifth of Code sessions.
And their finding is the point for this room: domain expertise, not coding skill, is what makes people effective with it. That is you.
Why Code for science work, and not chat? Because of what it leaves behind. A chat gives you a thread and a download. Code leaves a script you can rerun on next week's data, and a commit you can go back to.
Example: a student asks chat for a plot of reaction time per session and gets a PNG. Next week there is new data: ask again, and the bins and colours come out different. In Code the same request leaves one script; next week it is one command, the same figure on the new data, and the commit log says when anything changed.
My view, not a docs claim: you need to know what the right answer looks like far more than you need to know how to code.
